- 💥[Bugfix] Support Granian, which replaced uWSGI in Tutor. The plugin now overrides the `CMD` of the openedx image, so that the LMS and CMS containers start with `livedeps serve`: it downloads the dependencies, checks for new ones every minute, reloads the workers with `reload-granian` when they change, and runs Granian. This plugin can't be combined with another plugin that also sets `CMD` in the openedx image. (by @Faraz32123)
- [Improvement] Swap in new dependencies only once they are fully downloaded, so a failed download no longer deletes the current ones. (by @Faraz32123)
- [Bugfix] Fix the dependencies not being updated when they are uploaded again while a container is still downloading the previous ones. (by @Faraz32123)
